yasakani-dsh-ja: a Japanese language pack for the web screen of DeepSeek Harness

client.js holds Japanese translations of the user-interface texts of DeepSeek Harness 0.2.1-rc.2
(https://github.com/deepseek-ai/deepseek-harness, MIT License, Copyright (c) 2026 DeepSeek).
The translation was made by the YASAKANI authors. It is registered through the language interface of the screen
(addLanguage / register); no file of DeepSeek Harness is changed. client.js is a generated file.
